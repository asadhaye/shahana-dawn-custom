## 🚀 Common Tasks

### Configure Bridge Button Text
1. Go to **Online Store → Settings → Languages**
2. Search for `immersive_journey_bridges`
3. Edit the CTA keys (e.g., `collection_cta`)
4. Save and refresh storefront

**More details:** [Merchant Guide → Customizing Bridge Button Text](./MERCHANT_GUIDE_BRIDGE_SYSTEM.md#customizing-bridge-button-text)

### Add Bridge Button Image
1. Go to **Online Store → Customize → Sections**
2. Select the section containing the bridge button
3. Look for **Bridge Button Image** setting
4. Upload a custom image (400×300px recommended)

**More details:** [Merchant Guide → Customizing Bridge Button Images](./MERCHANT_GUIDE_BRIDGE_SYSTEM.md#customizing-bridge-button-images)

### Enable Preference Banner Auto-Dismiss
1. Go to **Online Store → Customize → Theme Settings**
2. Look for **Immersive Store Preferences**
3. Set **Preference Banner Auto-Dismiss** (in seconds)
4. Save and refresh

**More details:** [Merchant Guide → Auto-Dismiss Timeout](./MERCHANT_GUIDE_BRIDGE_SYSTEM.md#auto-dismiss-timeout)

### Extend the Bridge System
1. Read: [Developer Guide → Extending the Bridge System](./DEVELOPER_GUIDE_BRIDGE_SYSTEM.md#extending-the-bridge-system)
2. Choose your extension type (new entry point, custom styling, etc.)
3. Follow the implementation steps
4. Test with unit and integration tests

**More details:** [Developer Guide → Extending the Bridge System](./DEVELOPER_GUIDE_BRIDGE_SYSTEM.md#extending-the-bridge-system)

### Debug Bridge Button Issues
1. Open DevTools (F12)
2. Go to **Console** tab
3. Look for error messages
4. Check [Troubleshooting Guide → Bridge Button Not Appearing](./TROUBLESHOOTING_BRIDGE_SYSTEM.md#bridge-button-not-appearing)

**More details:** [Troubleshooting Guide → Bridge Button Issues](./TROUBLESHOOTING_BRIDGE_SYSTEM.md#bridge-button-issues)
