# Immersive Store Theme — Merchant Setup Guide

**Complete this guide to customize the immersive store for your brand.**

---

## Step 1: Access Theme Editor

1. Go to **Shopify Admin** → **Online Store** → **Themes**
2. Find the **Immersive Store** theme
3. Click **Customize** (or **Edit code** if you need advanced changes)

---

## Step 2: Configure Room Images

### In the Theme Editor:

1. Click **Immersive Canvas** section
2. You'll see settings for each room:
   - **Storefront Room**
   - **Lounge Room**
   - **Designer Houses Room**
   - **Occasions Room**
   - **Featured Collections Room**

### For Each Room, Upload:

- **Base Image (Desktop)** — Main background image (1920×1080 or wider)
- **Base Image (Mobile)** — Mobile version (900×1600 or similar)
- **Depth Map (Desktop)** — Grayscale depth map for parallax effect
- **Depth Map (Mobile)** — Mobile depth map

**Tip:** Depth maps should be grayscale images where lighter areas appear closer and darker areas appear farther away.

---

## Step 3: Configure Collections

### Designer Houses Room:

1. Scroll to **Designer Houses Room** section
2. Set up 3 collection hotspots:
   - **Slot 1 Collection** — Select your first designer collection
   - **Slot 1 Label** — Enter the designer name (e.g., "Suffuse")
   - **Slot 2 Collection** — Select your second designer collection
   - **Slot 2 Label** — Enter the designer name (e.g., "Soraya")
   - **Slot 3 Collection** — Select your third designer collection
   - **Slot 3 Label** — Enter the designer name (e.g., "Saad Bin Shahzad")

### Occasions Room:

1. Scroll to **Occasions Room** section
2. Set up 4 collection hotspots:
   - **Slot 1** — Eid Collection
   - **Slot 2** — Bridal & Mehndi
   - **Slot 3** — Luxury Formals
   - **Slot 4** — Casual Pret

### Featured Collections Room:

1. Scroll to **Featured Collections Room** section
2. Set up 3 collection hotspots:
   - **Slot 1** — Your featured collection 1
   - **Slot 2** — Your featured collection 2
   - **Slot 3** — Your featured collection 3

---

## Step 4: Configure Navigation & Logo

1. **Navigation Menu** — Select which menu to display in the immersive store header
2. **Store Logo** — Upload your brand logo (will appear in the ceiling overlay)

---

## Step 5: Configure Onboarding (Optional)

1. Check **Enable Onboarding** to show a welcome message
2. Set **Onboarding Title** (e.g., "Welcome to the Immersive Store")
3. Set **Onboarding Description** (e.g., "Explore our curated collections in 3D")
4. Set **Dismiss Label** (e.g., "Enter the store")
5. Check **Show Once** to only show the onboarding on first visit

---

## Step 6: Configure Flash Sale (Optional)

1. Click **Add block** → **Flash Sale Banner**
2. Check **Enable flash sale banner**
3. Enter your **Flash sale message** (e.g., "Flash Sale — 30% Off")
4. Set **Sale end date** in ISO 8601 format (e.g., `2026-12-31T23:59:59Z`)

---

## Step 7: Save & Publish

1. Click **Save** to save your changes
2. Click **Publish** to make the theme live

---

## Best Practices

### Images

- **Desktop images:** 1920×1080 or wider (16:9 aspect ratio)
- **Mobile images:** 900×1600 or similar (9:16 aspect ratio)
- **Depth maps:** Grayscale PNG or WebP (same dimensions as base image)
- **File size:** Keep under 500KB per image for fast loading

### Collections

- Use collections that represent distinct product categories
- Ensure each collection has at least 5-10 products
- Use clear, descriptive collection names
- Organize collections by season, occasion, or designer

### Hotspot Labels

- Keep labels short (1-3 words)
- Use your brand's terminology
- Make labels descriptive (e.g., "Eid Collection" not just "Eid")

---

## Troubleshooting

### Images Not Showing

- Check that images are uploaded and not deleted
- Verify image dimensions (desktop: 1920×1080+, mobile: 900×1600+)
- Clear browser cache and reload

### Collections Not Appearing

- Ensure collections are published (not draft)
- Verify collection handles match exactly
- Check that collections have products

### Hotspots Not Clickable

- Verify collection is selected in settings
- Check that collection has products
- Ensure hotspot label is not empty
